# Как управлять сайтом: памятка для владельца

Панель мастерской открывается по ссылке «Кабинет мастерской» внизу сайта или по адресу сайта с добавкой `/admin/`.

## Главное правило

Всё, что вы меняете, сначала сохраняется как **черновик** на вашем устройстве. Покупатели видят изменения только после кнопки **«Опубликовать»** вверху справа. Кнопка **«Предпросмотр»** показывает сайт с вашими правками в новой вкладке.

## Вход

Нажмите «Вход владельца» слева внизу и введите пароль мастерской. Вход действует 4 часа. Без пароля панель работает в деморежиме: можно пробовать что угодно, сайт для покупателей не изменится.

## Что где находится

| Хочу… | Раздел |
| --- | --- |
| добавить постройку, поменять цену, фото или описание | Каталог |
| скрыть постройку, не удаляя её | Каталог → «Скрыть» |
| изменить порядок карточек | Каталог → стрелки ↑ ↓ |
| поменять рассказ о мастерской, шаги заказа, ответы на вопросы | Тексты сайта |
| поменять телефон, Telegram, добавить MAX или ВКонтакте, режим работы | Контакты |
| включить новогоднее оформление | Обзор или Оформление |
| внести ИНН и другие реквизиты | Реквизиты |
| поменять заголовок на первом экране или строку объявления | Название и первый экран |

## Новая постройка

1. Каталог → «Добавить карточку».
2. Заполните название, раздел, размеры. Цену пишите цифрами без пробелов и знака рубля.
3. В поле «Комплектация» каждый пункт начинайте с новой строки.
4. Вкладка «Фото и модель»: загрузите главное фото и до шести дополнительных. Снимки можно брать прямо с телефона — панель уменьшит их сама.
5. «Сохранить карточку», затем «Опубликовать».

## Цены

Пока поле «Актуальная цена» пустое, покупатель видит цену из вашей публикации в канале с датой, например «Цена в публикации от 5 ноября 2025 г.». Когда вы вводите актуальную цену, на карточке появляется «Цена мастерской».

## Новогоднее оформление

Переключатель «Новогоднее оформление» есть на странице «Обзор». Включили — нажали «Опубликовать». Можно поставить галочку «Включать само по календарю» в разделе «Оформление»: тогда сайт станет новогодним 1 декабря и вернётся к обычному виду 15 января без вашего участия.

## Проверка сайта

На странице «Обзор» есть список «Проверка сайта». Он подсказывает, чего не хватает: реквизитов, режима работы, запасного способа связи, актуальных цен. Жёлтый значок — нужно сделать, зелёный — готово.

## Если что-то пошло не так

- **«Каталог уже изменился».** Сайт правили с другого устройства. Нажмите «Загрузить с сайта» и внесите правки ещё раз.
- **«Время сеанса истекло».** Войдите снова — черновик сохранился.
- **Поля закрыты замком.** Серверу сайта нужно обновление. Передайте разработчику файл `docs/DEPLOY.md`.
- **Передумали.** Кнопка «Отменить изменения» возвращает опубликованную версию.

Подробные ответы — в разделе «Помощь» внутри панели.
