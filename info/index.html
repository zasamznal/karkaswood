Данные и конфиденциальность

Просмотр каталога

Для просмотра работ, 3D-моделей и планировок регистрация не требуется. На сайте нет формы онлайн-заказа, ввода банковских реквизитов или оплаты.

Страницы размещены на GitHub Pages. Для загрузки актуального каталога браузер также обращается к серверу данных сайта. При этих запросах серверы получают технические сведения, включая IP-адрес и заголовки браузера. GitHub сообщает, что регистрирует IP-адреса посетителей GitHub Pages в целях безопасности. Сведения GitHub Pages о сборе данных.

Что сохраняется в браузере

Сайт сохраняет последнюю загруженную копию каталога, чтобы показать её при перебоях связи. Если вы редактируете сайт в деморежиме или кабинете мастерской, браузер также сохраняет локальный черновик. Данные привязаны к браузеру и устройству. Их можно удалить в настройках браузера, очистив данные этого сайта. При очистке удалится и черновик с неопубликованными правками.

При входе владельца сервер проверяет пароль и ограничивает частоту попыток входа. Ключ активного сеанса хранится в памяти вкладки и удаляется при выходе.

Обращение в мастерскую

В окне запроса вы можете выбрать тему и указать населённый пункт для расчёта доставки. Черновик с этими сведениями, выбранными моделями и размером кровати остаётся в памяти вкладки и очищается при закрытии окна. При нажатии «Открыть Telegram» текст передаётся в Telegram для подготовки сообщения. Вы можете изменить его и самостоятельно отправить мастерской. Политика конфиденциальности Telegram.

Чтобы уточнить, какие сведения о вашем обращении есть у мастерской, попросить их исправить или удалить, воспользуйтесь контактами для обращений.
